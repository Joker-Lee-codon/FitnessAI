# iPhone Analysis and System Page Overrides

## Scope

Applies to complete private-Alpha Analysis, Apple Health, Exercise Catalog, Sync & Recovery, Account & Privacy, and Support Matrix.

## Composition

- Analysis leads with a literal conclusion and evidence chart, then period metrics, exclusions, and a decision-oriented note.
- Catalog leads with canonical Exercise identity and support boundary before teaching content.
- Sync, privacy, and lifecycle screens use scoped ledger rows: object/copy → state → consequence → next action.
- Support Matrix uses a comparison table with text/symbol states; never a color-only heatmap.
- Apple Health uses capability-scoped rows and keeps local FitnessAI authority, optional HealthKit copies, and remote-AI exclusion visually separate.

## Charts

- Use Swift Charts with direct labels, exact point inspection, time-granularity control, and data-table alternative.
- Solid marks are effective confirmed inputs. Dashed marks or hatched regions indicate pending/excluded inputs.
- Calculation failure replaces the chart with cause, retained period/filter state, and Retry.
- Reduce Motion disables chart drawing; accessibility summaries announce the conclusion before point-level navigation.

## Lifecycle and Trust

- Never collapse local, synchronized, Apple Health-owned, research-uploaded, and exported copies into one generic data state.
- Export/deletion/restoration rows retain accepted, in-progress, scoped-complete, failed, and exception states.
- HealthKit read state never claims denial; use “暂无可读取数据” when no accessible data is observable.
- Account switch previews the prior local history and unsynchronized consequences before mutation.

## Accessibility

- Tables linearize at large Dynamic Type while retaining row/column context in accessibility labels.
- Charts expose a text summary and sortable/ordered data alternative.
- Every lifecycle row is one focus group with state, scope, consequence, and next action.
- Errors move focus to the affected row and do not dismiss the user's selected period, filter, or object.
