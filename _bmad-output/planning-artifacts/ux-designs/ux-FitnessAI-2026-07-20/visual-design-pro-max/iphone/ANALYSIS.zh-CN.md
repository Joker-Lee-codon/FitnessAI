# iPhone — Analysis / 训练分析

## 1. 目的与权威性

基于有效实际训练组解释周/月训练证据和已选主要动作趋势，但不能自动修改训练计划。

## 2. 进入与退出

- 进入：Analysis Tab、History 下钻、动作趋势路径。
- 退出：更改周期/动作、检查精确点/数据表、复核被排除场次、有意编辑下一计划。

## 3. 构图

1. 周期和已选动作。
2. 字面结论（“负重上升，完成次数稳定”）。
3. 直接标注趋势图。
4. 由实际训练组计算的场次/组数/容量指标。
5. 排除/待更新边界和数据来源说明。
6. 不自动应用的决策型下一步。

## 4. 组件

`TrendEvidenceChart`、指标账本、`FactStateLabel`、排除边界、`SystemStatePanel`。

## 5. 必需状态

冷启动；周期无数据；就绪；不完整数据被排除/标注；冲突待更新；选中数据点；计算失败；离线缓存分析。

## 6. 交互与无障碍

图表提供 44 pt 点目标、直接数值、VoiceOver 摘要和数据表。已确认/有效输入使用实线；待处理/冲突输入使用虚线/排除并明确命名。Reduce Motion 移除图表绘制。结果绝不能自动修改计划。

## 7. 需求与流程

FR-037–FR-040、FR-046、FR-063；UJ-2。
