# iPhone — Exercise Catalog

## 1. Purpose and Authority

Presents canonical Exercise identity, target body areas, movement/substitution attributes, teaching content, and named support boundaries.

## 2. Entry and Exit

- Entry: search/catalog route, plan substitution, Session Review correction, Support Matrix deep link.
- Exit: select/correct canonical Exercise, choose an explicit substitute, return to exact field, continue manual recording.

## 3. Composition

1. Search and canonical Exercise title.
2. Support boundary before the first affected action.
3. Primary/secondary target areas and movement attributes.
4. Licensed/owned teaching image and text.
5. Substitute comparison or manual-only fallback.

## 4. Components

Search field, canonical identity header, `SupportBoundaryNotice`, attribute ledger, media state, `TitaniumPrimaryAction`.

## 5. Required States

Cold load; ready; media unavailable; supported; limited; manual-only; unsupported; canonical mapping unresolved; search empty/error.

## 6. Interaction and Accessibility

Media has meaningful alt text or is hidden if decorative. Missing media does not hide teaching text. The page never presents wrist-only observations as precise full-body form judgment. Substitute differences are literal and chosen by the user.

## 7. Requirements and Flows

FR-030–FR-032, FR-049–FR-053; UJ-1, UJ-4, Flow 8.
