# iPhone — Beginner Plan (Post-MVP, Gated)

## 1. Purpose and Authority

Defines the future visual surface for a short card-based plan intake and explicit proposal approval. This page is **not MVP navigation or implementation scope** until FR-054–FR-060 and NFR-SAFE-001 release gates pass.

## 2. Entry and Exit

- Future entry: explicit Beginner Plan request from Today & Plans.
- Exit: save intake draft, stop affected scope, review proposal, approve import, decline, or seek qualified offline guidance when required.

## 3. Composition

1. Step identity and progress without urgency.
2. One visible question group at a time with persistent labels.
3. Mandatory injury/limitation disclosure and literal scope consequence.
4. Safety stop boundary before any affected recommendation.
5. Draft proposal ledger and explicit Approve/Decline; no automatic import.

## 4. Components

Step ledger, labelled form rows, safety `SupportBoundaryNotice`, plan proposal `PlanDiffReview`, `TitaniumPrimaryAction`.

## 5. Required States

Intake incomplete; disclosure; warning-sign stop; unaffected-scope continuation; draft; safety review unavailable; proposal; approved; declined; commit failure.

## 6. Interaction and Accessibility

Questions have visible labels and errors. Uncertainty/declined answer never permits severity inference. Warning-sign state stops the affected scope without diagnosis. The user explicitly approves before canonical mapping/import.

## 7. Requirements and Flows

FR-054–FR-060 (Post-MVP), NFR-SAFE-001; UJ-4 (Post-MVP).
