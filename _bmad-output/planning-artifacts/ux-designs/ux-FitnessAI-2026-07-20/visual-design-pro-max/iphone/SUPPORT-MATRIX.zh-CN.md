# iPhone — Support Matrix / 支持矩阵

## 1. 目的与权威性

明确 Watch、iPhone、OS、动作、信号和已批准负重语义组合的支持、有限、仅手动和不支持状态。

## 2. 进入与退出

- 进入：Onboarding、Workout Entry 边界、Exercise Catalog、支持/设置。
- 退出：精确手动回退、兼容设备指南、规范动作纠正、返回受影响操作。

## 3. 构图

1. 矩阵版本和最近验证日期。
2. 按设备/OS/动作/语义筛选。
3. 带符号 + 字面状态的比较账本。
4. 每行精确限制、保留字段和回退。
5. 矩阵不可用状态不能编造支持。

## 4. 组件

筛选控件、`SupportBoundaryNotice`、比较账本、`FactStateLabel`、`SystemStatePanel`。

## 5. 必需状态

加载；支持；有限；仅手动；不支持组合；低置信度；矩阵版本不可用；离线缓存矩阵。

## 6. 交互与无障碍

不使用只依赖颜色的热力图。每行对设备/动作、状态、限制和回退进行分组。返回时保留筛选状态。不支持不能表现为没有解释的失效控件。

## 7. 需求与流程

FR-049–FR-053，以及 PRD 负重语义/设备发布门槛；Flow 8。
